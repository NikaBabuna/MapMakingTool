# F-035 — Precedence + area flux + motion intent

**Goal:** G-008  
**Status:** `done`

## Job (approved)

From standing `boundaries` + `plate_registry`, write STATIC **`area_flux`** and **`motion_intent`** at Step 0 and each generation. Collide contacts get precedence (smaller area loses; ties → lower id). Interaction stage only — budgets and preferred Δv; do not apply flux, integrate velocity, fission, or rewrite orogeny. Cylinder topology stays (wrap X; polar Y; no latitude-weighted partition — deferred). Constant `plate_velocity` + advection remain the motion source until F-037.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Precedence | COLLIDE only: loser = smaller registry area; tie → lower plate id |
| Flux unit | 1 cell per `BoundaryContact` |
| SEPARATE flux | Both plates **+1**; sink **−2** |
| COLLIDE flux | Loser **−1**; winner **0**; sink **+1** |
| PASS_BY flux | 0 |
| `area_flux` | Per-plate `Δarea[]` + `sinkΔ`; `sum(Δarea) + sinkΔ == 0` |
| SEPARATE motion | Ridge push **away**: A **(−nx,−ny)**; B **(+nx,+ny)** |
| COLLIDE motion | Dampen (apart): A **(−nx,−ny)**, B **(+nx,+ny)**; slab pull on loser into boundary: loser A **+(nx,ny)** / loser B **+(−nx,−ny)** |
| PASS_BY motion | 0 |
| Topology tweak | **A** — keep cylinder partition; no cos(lat) metric |
| Out of scope | ApplyFlux / flood / fission / death; IntegrateVelocity; orogeny rewrite; studio restyle; latitude-aware Voronoi |

# F-051 — Runner shell (foundation)

**Goal:** G-009  
**Status:** `done`

## Job (approved)

Turn the studio into a quiet simulation runner with stable **layout slots** and two visual systems (gray chrome + physical map palette). Top bar: brand + host dot; center Play/Pause/Speed (`1x`/`2x`/`4x`/`Fastest`); right Reset view. World rail: step, size, seed, reset world. Map HUD: layer switch bottom-left. Terminal: continuous surface, inline prompt, readable gray-on-dark. Map paint: physical atlas colors.

**Out of scope:** Perf/detail panel content (F-052); residual polish pass (F-053); new command verbs; engine edits.

# F-048 — Noun/verb command language

**Goal:** G-009  
**Status:** `done`

## Job (approved)

Replace the placeholder flat verb bag with a shared **noun-path + verb** operator language over one ProductSession: pool information, product construction (schema/systems), and actions (advance, diag). Single execute entry for CLI + MapController + MapHost. Deprecated aliases for old verbs through G-009. No terminal scrap (F-050). No full CLI runner loop (F-049). No verb names in Systems/Pool.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Grammar | `<noun-path> <verb> [args…]`; `help […]`; `list <noun>` also verb-first |
| Nouns | `session`, `pool`, `schema`, `systems`, `diag` |
| Verbs | `list`, `get`, `advance`, `help`, plus diag `on`/`off`/`clear` |
| Aliases | Old verbs kept for G-009 (deprecated) |
| Grid get | Summary by default; `get X Y` for cell |
| Dump | `session get dump` (+ alias `dump`) |
| Engine | Read ports `systems()` / `fieldSchema()` only |

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | Catalog + `help` / `help <noun\|verb>` describe nouns and verbs. | met |
| FR-2 | Noun/verb forms work: `session get`, `session advance [N]`, `list pool\|schema\|systems\|diag`, `pool.<field> get`, `schema`/`systems` get, `diag` get/on/off/clear. | met |
| FR-3 | Single `CommandDispatch.execute` entry used by CLI, MapController, MapHost (no duplicate parser). | met |
| FR-4 | Deprecated aliases preserve prior success outputs for `status`, `advance`, `dump`, `at`, `layers`, `stats`, `diag …`. | met |
| FR-5 | Docs/ADR: shared noun/verb model; placeholder retired for this catalog; no Systems/Pool verb coupling; suite green; no F-049/F-050 claims. | met |

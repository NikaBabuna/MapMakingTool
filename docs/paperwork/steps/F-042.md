# F-042 — Diagnostics infrastructure

**Goal:** G-009  
**Status:** `done`

## Job (approved)

Build a controllable diagnostics facility owned by `ProductSession`: named collectors, enable/disable, bounded sample history, and CLI query/control. Wire first collectors (`advance.wall`, `heap.used`, `heap.max`, `paint.wall`). Replace cramped one-shot WIP. No physics/topology change. No engine edits.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Owner | Session hub (not Pool; not engine) |
| Model | Named collectors + enable/disable + ring history |
| First collectors | `advance.wall`, `heap.used`, `heap.max`, `paint.wall` |
| CLI | `stats`; `diag list` / `on` / `off` / `clear` |
| Phase / HTTP | Deferred (new collectors later) |
| Default capacity | 64 samples per collector |

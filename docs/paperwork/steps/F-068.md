# F-068 — Functional test suite

**Status:** `done`  
**Type:** `Modification`  
**Goal:** G-011

## Job

The test suite states what the app does and proves it by running the code.
- **What a test is:** each test checks one outcome of one layer: the engine, a world phase, a whole generation, the session, the CLI, the Java studio (controller, raster, HTTP host), and the web front.
- **Web front:** the web front gets its own tests in Vitest, which `./mvnw test` runs.
- **What tests don't read:** no test reads a document, and none reads another file's source or config as text.
- **Links:** F-068 states the app's functional requirements as they stand. Its test map links each requirement to the test file(s) that prove it, and each test names the F-068 requirements it proves. One test may prove several.
- **Old tests:** all 282 current tests are retired. F-068 lists each one with the requirement that now covers its claim, or the reason it has none: it read a doc, it read source text, or the build already enforces it.
- **Where the expected values come from:** the wiki, the journeys, the style guide, an ADR, or the architecture paper, never from running the code.
- **Defects:** a test that fails because the code is wrong stays enabled and red, and is listed under **Known defects** with the failing assertion. The app code is not changed.
- **Goal close:** G-011's claims are corrected to one wording, and the Goal is closed.

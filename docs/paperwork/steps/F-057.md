# F-057 — Ridge mint + Simulation restart

**Goal:** G-010  
**Status:** `done`

## Job (approved)

Mint new thin oceanic lockers at advection-gap cells so rifts do not inherit a neighbor’s mountain. Plate-id flood stays (F-043 / F-044). Unique destinations still ride (F-056). Contested cells keep the lowest-plate source locker. Add Simulation menu items to restart the UI (page reload) and restart the engine (new `ProductSession`, same seed). No buoyancy, suture, or locker GC. No `engine` source edits.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Gap | Advection `claims == 0` only |
| Plate fill | Unchanged F-044 flood |
| Occupancy fill | Mint; do not copy neighbor locker ids |
| Contested (2+ claimants) | Keep lowest-plate riding locker; no mint |
| Mint thickness | \(T_{ocean}=8\) |
| New ids | Append to locker table, raster order (y, then x) |
| Orphan lockers | Leave them (no compact) |
| Collide inherited occupancy | Out of scope (F-058) |
| Assembly | `RidgeCreate` after occupancy remap + orogeny stamps, before isostasy |
| Restart UI | `window.location.reload()`; engine session unchanged |
| Restart engine | Recreate `ProductSession` same geometry + seed; Step 0; works while busy; pause play; in-flight advance must not clobber |
| Engine | No `engine` production edits |

# F-037 — Edge-driven velocity integrate

**Goal:** G-008  
**Status:** `done`

## Job (approved)

Each generation, turn standing `motion_intent` into updated plate velocities so motion is edge-driven. Seeded random `{-1,0,1}` stays Step-0 initial only — not frozen forever. Advection and fission keep using `plate_velocity` / registry, but those values change from intent. No orogeny rewrite; no studio.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Integrate formula | Per axis: `v' = clamp(v + sgn(intent), -1, 1)` with `sgn(0)=0`, else ±1 |
| Zero intent | Velocity unchanged on that axis |
| All-stop guard | If every plate is `(0,0)` after integrate → force plate `0` to `(1,0)` |
| Pipeline order | TraceBoundaries → BoundaryInteraction → **IntegrateVelocity** → ApplyGeometry → Orogeny |
| Step 0 | Seed velocities from mix; no integrate until generation ≥ 1 |
| Writes | STATIC `plate_velocity` + matching `plate_registry` velocities (standing plate count) |
| Out of scope | Intent accumulation rules; orogeny-from-boundaries (F-038); studio (F-039/40); engine edits |

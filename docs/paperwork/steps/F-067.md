# F-067 — Architecture paper of the whole app

**Status:** `done`  
**Type:** `Documentation`  
**Goal:** G-011

## Job

The architecture shelf becomes a complete engineering paper of the app as its code stands at the start of this Step (commit `ac45a3c`), test suites excluded.
- **Layout:** one area per layer (engine, world, session, CLI, studio, with the web front as a chapter of studio), under a program page that also states the running processes.
- **Two explanations per mechanism:** every mechanism of the main source has a page, and every page explains it in plain English and again as a mathematical model written in LaTeX.
- **Code backing:** every procedure step names the method that performs it, linked to its source file. The lines that implement a central formula are quoted word for word.
- **Rules and records:** the architecture blueprints gain the sections this form needs. A decision record says why. The entrance and the code doors point at the new pages.
- **Transition:** the documentation transition you kept on 2026-09-25 is adopted into this Step.
- **Tests:** tests that read documents are not edited. Any that go red are disregarded, on your instruction.

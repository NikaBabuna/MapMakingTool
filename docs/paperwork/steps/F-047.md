# F-047 — Raster + host memory

**Goal:** G-009  
**Status:** `done`

## Job (approved)

Cut memory churn on the map paint + HTTP raster path: reuse/flatten paint buffers, cache packed host bytes until step/layer invalidate, soak witness O(1) retained buffers, keep RGB byte-identical. No engine edits. No physics. No F-048+ commands/chrome.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Scope | `ui` — ElevationRaster, MapController, MapHost |
| Raster storage | Flat `int[]` + **double-buffer** reuse when width×height unchanged |
| Host | Cache/reuse packed `byte[]`; invalidate on paint generation / step / layer |
| Paint formulas | Unchanged |
| Soak | ≥20 advance+raster cycles → O(1) packed-body allocations |
| Wire format | Unchanged |
| Engine / product physics | No edits |

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | Paint path does not allocate a new full-size buffer on every paint when dimensions are unchanged (reuse or flat buffer); witnessed. | met |
| FR-2 | `GET /api/raster` serves from a cached/reused packed body while step index + layer are unchanged; packing runs again only after invalidate. | met |
| FR-3 | Same elevation + plates + layer → byte-identical packed RGB vs current formulas. | met |
| FR-4 | Soak: ≥20 advance+raster cycles leave O(1) cached packed buffers — not one retained body per cycle. | met |
| FR-5 | `paint.wall` still records; docs note cache/reuse; no `engine` production edits; suite green; no F-048+ claims. | met |

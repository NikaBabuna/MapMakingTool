# F-065 — Architecture paper

**Goal:** G-011
**Status:** `done`

## Job (approved)

Write `docs/architecture/` as one paper arranged by abstraction. A page states its own mechanism and points at the finer page. The procedure lives on that finer page. Where an old spec and the source disagree, the page follows the source. Step ids and Goal ids are not the explanation. The changelog keeps that history.

`docs/architecture/README.md` is the abstract: the four levels, what question each answers, and no procedures.

| Level | What it explains | Where it lives |
|-------|------------------|----------------|
| Program | The four modules, the dependency direction, Java 21 | `docs/architecture/program.md` |
| Host | What one engine step does, whether or not a world is attached | `docs/architecture/host/` |
| World | What one generation does to the grids, and each procedure that writes them | `docs/architecture/world/` |
| Studio | How settled grids become pixels, polls, and commands | `docs/architecture/studio/` |

`host/README.md` is the step transaction in the order the engine runs it. Each stage points at the page that owns it: `pool`, `events`, `systems`, `merge`, `determinism`, `user`, `diagnostics`. Those pages carry the rules that live in `docs/engine/specs/` today, rewritten as what the code reads, what it writes, and what is true afterwards. The framework glossary moves to `host/glossary.md`. Gaps that are still undecided stay on `host/open-questions.md`.

`world/README.md` names the fields and the pipeline `ProductHost` wires, in this order, each name pointing at its page: TraceBoundaries → BoundaryInteraction → IntegrateVelocity → ApplyGeometry → Orogeny → RidgeCreate → MarginRelief → ContinentalCollide → ThicknessToElevation. The pages under that are `plates` (seed, partition, sphere), `boundaries` (trace, kind, flux, motion intent), `motion` (integrate, advection, flood, fission, death), and `crust/` with one page each for precedence, subduct, ridge, margin, orogeny, collide, and isostasy. Each page names the type that implements it and the quantities the code uses: view 1920×1080, 12 to 24 plates, ocean thickness 8, land at 16, cap 32, elevation = thickness − 8.

`studio/README.md` points at `session` (the lock, advance, dump, diagnostics), `raster` (packing, ramps, hillshade, layers), and `host` (HTTP cache, play timer, shared command language).

`docs/product/` concept pages and `docs/project/project.md` stay as they are. `docs/architecture.md`, `docs/engine/`, and `docs/product/architecture.md` go away once their facts have a page. This Step does not close G-011.

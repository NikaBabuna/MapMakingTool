# F-060 — Continental suture + arc + cap

**Goal:** G-010  
**Status:** `done`

## Job (approved)

Add one Sub-System, `ContinentalCollide`, in the existing tectonics System. It runs after margin relief and before isostasy. Ocean–ocean collisions thicken the winner into an arc that can cross \(T_{land}=16\) in that same step. Continent–continent collisions thicken both sides and stop at a cap. Plate ids do not merge. Elevation stays thickness minus 8. No `engine` edits. Goal close stays F-061.

Sea-level paint (elevation 0 as shallow ocean) is out of this Step.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| When | After `MarginRelief`, before `ThicknessToElevation` |
| Arc | Ocean–ocean only. The winner’s locker gets **+8 once** this step. If that is still below 16, the locker is set to 16 |
| Suture | Continent–continent only (both lockers already ≥ 16). **Each side +4 once.** Neither locker is consumed. Plate ids stay. Flux stays 0 |
| Grain | One write per locker per step, from the post-move contact cells |
| Cap | **32.** A locker already at 32 is left alone. A write that would pass 32 stops at 32. No erosion |
| Left alone | Ocean–continent, pass-by, and rifts add nothing |
| Elevation | Still `thickness − 8` |
| Engine | No production edits |

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | On an ocean–ocean collide, the winner’s locker increases by 8 once, clamped at 32. When margin left it at 15 or below, one step leaves it at 16 or above. The loser plate is not welded onto the winner. | met |
| FR-2 | On a continent–continent collide, each side’s locker increases by 4 once, clamped at 32. Neither occupancy is consumed. Both plate ids remain. | met |
| FR-3 | A locker already at 32 stays 32. Ocean–continent, pass-by, and diverge add 0 from this writer. | met |
| FR-4 | After a later generation, cells that still hold that locker are still at 16 or above. Elevation equals thickness minus 8. Same seed and step count stay identical. One tectonics System. No `engine` edits. | met |

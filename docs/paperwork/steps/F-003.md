# F-003 — Events + claiming + unmatched log + logging foundation

**Goal:** G-001  
**Status:** `done`

## Job (approved)

Extend the Step loop with an event buffer, category tree + ancestry claiming, unmatched-event reporting (ADR-006), and a logging/diagnostics foundation (SLF4J + capturable diagnostics) so Steps, emissions, claims, and unmatched events are visible while the engine runs. Stub claimers only; no Sub-Systems / merge / View.

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | During a Step, the Pool can emit **events** into a shared **event buffer**, each with a **category**. | met |
| FR-2 | A **category tree** supports ancestry. A claimer assigned `C` claims events whose category is `C` or a **descendant** of `C`. | met |
| FR-3 | An event claimed by **no** claimer is reported via **`EngineDiagnostics`** (not silently dropped). | met |
| FR-4 | Buffer is filled during that Step’s Pool compute and **not refilled** before the Step ends; after settle the buffer is **empty**. | met |
| FR-5 | Claim / unmatched outcomes for a Step are **observable in tests** without full System execution. | met |
| FR-6 | **Logging foundation:** `engine` depends on **SLF4J API** only (no Logback in `engine`). Default diagnostics bridge to SLF4J. At least: Step start/settle (DEBUG), event emit (DEBUG), claim (DEBUG), unmatched (WARN). | met |
| FR-7 | Tests can attach a **recording** diagnostics sink and assert unmatched (and optionally other) records without scraping stdout. | met |
| FR-8 | Prior Steps stay green; `engine` still has no UI/CLI/`product` compile deps. Binding for tests may use `slf4j-simple` (test scope). | met |

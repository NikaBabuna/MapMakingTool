# F-073 — Studio and tooling organised

**Status:** `done`  
**Type:** `Cleanup`  
**Goal:** G-012

## Job

The studio's code gets the treatment F-071 and F-072 gave the engine, product and command line. That covers the ui module's Java side, the web front, the desktop shell, and the repository's build and tooling folders. The Java code is sorted into packages named with the studio paper's words, and the tests follow their code. Every name and file header meets the conventions page. Every folder that isn't exempt gets a README that explains its code in depth, plus a row on the navigation map. The studio pages of the paper hand their code quotes and member tables over to those READMEs, and keep the concepts, maths and wire formats. Nothing the app does changes.

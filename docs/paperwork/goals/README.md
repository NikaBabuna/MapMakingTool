# Goals

One file per Goal. The index, including the Active Goal line, is [../goals.md](../goals.md). Write one from the [goal blueprint](../../protocol/blueprints/paperwork/goal.md).

Each Goal file holds, in order, its status and what came before it, the result it wants, what it refuses, the decisions already made for it, the claims a witness must prove, its planned Steps, and its progress.

| Page | Read it when |
|------|----------------|
| [../goals.md](../goals.md) | You need which Goal is active, or the status and result of any Goal |
| `G-0xx-<slug>.md` | You need one Goal in full: its result, refusals, decisions, claims, and planned Steps. The index links each file |

# Pointers

A pointer is a link that names the next document. Follow one. Do not open the documents beside it.

| Need | Pointer home |
|------|----------------|
| Which room of conduct | [../README.md](../README.md) |
| Which flow | [../environment/dispatch.md](../environment/dispatch.md) |
| Which document kind to write | The flow step, then [../blueprints/README.md](../blueprints/README.md) |
| What this folder is | That folder’s `README.md` |
| Where every doc lives | [../../navigation.md](../../navigation.md) |
| Which Goal is active | [../../project/goals.md](../../project/goals.md) |
| Which Steps that Goal contains | The active Goal’s Step table |
| Whether a Step is in progress | The step registry |

A page that is not reachable from these homes is not a required read.

# Bounds

Open:

1. The protocol door, then the environment door, then dispatch and the dictionary.
2. The goal index, the active Goal, the step registry row, and that Step’s record if it exists.
3. The one blueprint for the document kind the flow names.
4. The one flow the dispatch named.

Leave closed:

- Sibling pages in a folder you entered for one link
- Other shelves
- Other flows
- History records, unless the flow says to append one
- Source, unless the flow is **Implement** or **Record source**

This folder is read the same way. The navigation door is enough until a step names `pointers.md` or `bounds.md`.

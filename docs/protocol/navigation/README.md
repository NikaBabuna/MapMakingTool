# Navigation

How an agent finds the one thing it needs and reads only that, so its context holds answers instead of files. This room never edits files. The map of this repository is [../../navigation.md](../../navigation.md).

| Page | Read it when |
|------|----------------|
| [reading.md](reading.md) | You are about to open, search, or run anything, and need the cheapest way to get only the part you need |
| [bounds.md](bounds.md) | You need what to read at the start of a chat, what a flow allows you to open, what must stay closed, or when to stop |
| [pointers.md](pointers.md) | You have a question and need the one page that answers it |
| [code.md](code.md) | You need a piece of source, a test, or a caller, without reading a module |
| [walks.md](walks.md) | You want to see a question followed end to end at low cost |

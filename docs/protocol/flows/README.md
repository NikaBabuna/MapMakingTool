# Flows

Bookkeeping. Each file holds named algorithms. A step names a document kind. Navigation resolves the kind to a path. The witness is the check named by the implementation paper. This room does not name that command.

Choose a flow only from [../environment/dispatch.md](../environment/dispatch.md).

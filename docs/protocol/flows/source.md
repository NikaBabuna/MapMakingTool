# Source flows

## Record source

When source is added or changed:

1. New files carry the source header from the source blueprint.
2. A new landmark folder gets a door from the readme blueprint.
3. Update the implementation paper for that module.
4. Update the spec page when the change is framework behavior.
5. Update the framework glossary when a new public framework word appears.
6. Leave the Step record’s test map to **Implement**.

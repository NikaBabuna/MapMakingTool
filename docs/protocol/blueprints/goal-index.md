# Goal index

**Kind:** goal index  
**Document:** `docs/project/goals.md`

## Body

1. The only Active Goal line in the repository: `**Active Goal:**` and a link to the Goal document.
2. A table: id, name, status, link. Status is `not started`, `in progress`, `done`, or `abandoned`.
3. A pointer to the step flows.

## Must not

Be copied onto the doors.

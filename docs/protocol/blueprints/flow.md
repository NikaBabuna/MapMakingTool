# Flow page

**Kind:** bookkeeping algorithm  
**Documents:** `docs/protocol/flows/goals.md`, `steps.md`, `structure.md`, `source.md`, `judgment.md`

## Body

Named algorithms. Each algorithm is an ordered list of edits. A step names a document kind, not a tool.

## Must not

Name a language, a build tool, or a witness command. Restate the dispatch table.

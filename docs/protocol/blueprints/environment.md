# Law page

**Kind:** environment page  
**Documents:** `docs/protocol/environment/territory.md`, `authority.md`, `conduct.md`, `engagement.md`, `phase.md`

## Body

Prose or a short table that states one part of the global order. `territory.md` names the shelves and the two work levels. `phase.md` names the depth rule.

## Must not

Include the dictionary table or the dispatch table. Those kinds have their own blueprints. Name a language, a build tool, or a witness command.

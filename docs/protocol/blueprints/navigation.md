# Doc map

**Kind:** entrance map  
**Document:** `docs/navigation.md`

## Body

1. Pointers to the protocol door and the goal index. Name the active Goal by id. Do not use an Active Goal sentence that copies the index.
2. A section per shelf or current folder, each opening with that folder’s door.
3. A table of documents: link and status (`Active`, `Draft`, or `Historical`, plus a short fact when needed).
4. The landmark code folders and their doors.

## Must not

Be the only copy of a mechanism. Duplicate a blueprint.

# Paperwork

Forms for the progress records under `docs/paperwork/`, and the naming rules for Goal, Step, and decision ids.

**Why:** Progress records have their own forms because flows write and search them by exact line formats. The forms of Goal, Step, and decision records, their indexes, the roadmap, the backlog, and the changelog belong here, with the rules for naming ids. When each record is written belongs to the Goal and Step flows.

| Page | Read it when |
|------|----------------|
| [goal-index.md](goal-index.md) | You are writing `docs/paperwork/goals.md`, the Active Goal line, or need the next Goal id |
| [goal.md](goal.md) | You are writing a Goal file `docs/paperwork/goals/G-0xx-<slug>.md`, or need the slug rule |
| [step-registry.md](step-registry.md) | You are writing `docs/paperwork/steps.md`, or need the next Step id |
| [step.md](step.md) | You are writing a Step record `docs/paperwork/steps/F-0xx.md` |
| [decision-index.md](decision-index.md) | You are writing `docs/paperwork/decisions.md`, or need the next ADR number |
| [decision-record.md](decision-record.md) | You are writing a decision record `docs/paperwork/decisions/ADR-0xx-<slug>.md` |
| [changelog.md](changelog.md) | You are adding a line to `docs/paperwork/changelog.md` |
| [roadmap.md](roadmap.md) | You are writing `docs/paperwork/roadmap.md` |
| [backlog.md](backlog.md) | You are writing `docs/paperwork/backlog.md` |

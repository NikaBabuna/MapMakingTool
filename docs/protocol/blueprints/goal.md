# Goal

**Kind:** one Goal  
**Documents:** `docs/project/goals/G-0xx-*.md` (for example `G-011-docs-restructuring.md`)

## Body

1. Status.
2. Result we want, as numbered claims.
3. Out of scope.
4. Decisions for this Goal.
5. Claim checkboxes.
6. Step table: id, intent, status.
7. Progress counts.

## Must not

A session section. Step requirements. Those live in the Step record.

# Messages

Forms for chat messages that [../../core-workflow.md](../../core-workflow.md) names as fixed forms. Other message skeletons live in the flow that sends them.

**Why:** A few chat messages have fixed forms because the core workflow requires them in every chat. Only the forms the core workflow names belong here; any other message's skeleton lives in the flow that sends it.

# Protocol

Product-independent conduct. An agent works only inside the flows named by the environment. It does not invent a write sequence.

**Goal index:** [../project/goals.md](../project/goals.md)

Open a room through its README. Leave the other rooms closed until the turn needs them.

| Order | Room | When |
|-------|------|------|
| 1 | [environment/](environment/README.md) | Before any other room. Territory, law, dictionary, and which flow runs |
| 2 | [navigation/](navigation/README.md) | When acquiring information to choose that flow |
| 3 | [flows/](flows/README.md) | When the dispatch names a flow |
| 4 | [blueprints/](blueprints/README.md) | When a flow says to write a document |

The other shelves (concept, implementation, history) stay on their current paths until their own Steps. The blueprints name those paths.

# F-053 — Runner UI infrastructure + QoL

**Goal:** G-009  
**Status:** `done` — Accepted 2026-09-20

## Job (approved)

Formalize front-end chrome into data-driven infrastructure: a panel registry, a menu-bar descriptor model on its own row, and resizable persisted layout — plus stronger panel/rail separation, a brighter elevation palette, and five QoL features. Future panels and menu items arrive as descriptor entries, not new rail JSX. No new CLI verbs, no collectors, no physics retune, no engine edits. F-054 (Goal close) stays out.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Menu bar | Own slim row **above** the transport bar (File · Edit · View · Simulation · Help) |
| Stub items | Rendered `aria-disabled` and inert — infrastructure for later |
| Panels | Registry descriptors (`id`, `title`, `dock`, `order`, `defaultOpen`, `collapsible`); rails map the registry |
| Layout | Drag-resizable rail widths + terminal height; persisted; **View → Reset layout** |
| Palette | Brighter land + ocean stops; hillshade formula unchanged |
| QoL | Shortcuts overlay, Advance N, copy seed, steps/sec, Terminal Clear |
| ADR | **None** — alpha; descriptor model documented as subject to change |

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |

| FR-5 | Rails and panels use new separation tokens (`--panel-edge`, `--gutter`, `--rail-bg`); stage, rails, and panels read as distinct surfaces. | met |

| FR-7 | QoL: shortcuts overlay (`?` / Help → Shortcuts) listing every key; Advance N field via existing `session advance N`; copy-seed control; steps-per-second in Perf (from `advance.wall`); Terminal Clear (UI transcript only, no new verb). | met |
| FR-8 | Docs/SYNC: style guide, flows, glossary, product architecture, changelog; no `engine` production edits; no `JFrame` in new tests; F-054 not claimed; descriptor model labelled alpha (no ADR). | met |

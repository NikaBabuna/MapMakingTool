# F-015 — First generative process

**Goal:** G-003  
**Status:** `done`

## Job (approved)

Wire generation onto the host: a product category tree, an emission policy that ticks after Step 0, and one `EngineSystem` that applies documented collision uplift. Step 0 stays a seed (zero elevation + `plates` layer from `WorldSpec.seed`). Relief appears after N advances. Rule lives in the wiki. No `engine` production edits. No climate. No ASCII dump / Goal close (F-016).

**Out of scope:** F-016 determinism goldens / headless dump / G-003 close; climate; moving plates; Wilson cycle; product CLI/UI; engine ports.

**Decisions (approved):** two-plate vertical suture; `xBoundary = 1 + floorMod(seed, width-1)` when `width > 1` (`width == 1` → boundary `1`, all plate 0); 4-neighbor contact +1 per generation Step; `plates` Pool layer, merge Constant; seed not stored as its own field; category `world/tectonics`; tree authored in product Java (ADR-009).

# F-044 — Earth-like fission + readable borders

**Goal:** G-009  
**Status:** `done`

## Job (approved)

Only substantial breakaways become new plates; largest component keeps parent id; thin/tiny scraps absorb; Plates layer uses east/south boundary stroke. No poles/UI. No engine edits.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Min new-plate size | ≥ 0.5% of width×height **and** min axis span &gt; 2 |
| Undersized split pieces | Sink-flood into neighbors |
| Parent id | Largest component keeps old id |
| Velocity | Children inherit vx/vy |
| Thin absorb | Span ≤ 2 **and** area &lt; min-new-plate size |
| Area crumb | &lt; 0.05% (keep) |
| Paint | East and/or south foreign neighbor only |
| Out of scope | Poles; intentional rift birth; kind colors; CLI/UI |

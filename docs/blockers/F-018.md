# F-018 — Large colored map UI + loading

**Goal:** G-004  
**Status:** `done`

## Job (approved)

Add a headless elevation raster and a product Swing window. Launch uses `WorldSpec.VIEW` (512×512, seed 0). The window opens at **Step 0** (flat field). Paint is an **absolute** height ramp, one pixel per cell. **Advance** runs one generation Step **off the EDT** and shows status **Working...** (Advance disabled; extra clicks ignored) until settled. Tests cover raster + controller only — **no `JFrame`**. Skeleton `cli` / `ui` unchanged. Dump golden / `WorldSpec.DEFAULT` unchanged. **Close G-004** (Active Goal none).

**Out of scope:** plate motion, climate, pan/zoom, legend, biomes, rewriting skeleton UI, engine ports, changing DEFAULT, stretch-to-max coloring, auto-advance on launch.

**Decisions (approved):** open at Step 0; absolute ramp clamp 32, lerp (12,10,18)→(255,196,96) with integer formula; `WorldSpec.VIEW`; `ElevationRaster` + `MapController` (no Swing) + `MapFrame`/`ProductApp`; injected executor; busy = disable Advance + status `Working...`; one Advance = one generation Step; close G-004.

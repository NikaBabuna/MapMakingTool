## Paint formulas (approved, stored)

Integer arithmetic, truncating division. Packed RGB `0xRRGGBB`.

### Land ramp (`e >= 0`) — unchanged from F-018

```
e = min(elevation, 32)
R = 12 + (243 * e) / 32
G = 10 + (186 * e) / 32
B = 18 + (78 * e) / 32
```

### Ocean (`e < 0`)

Constant for every negative cell: **R=18, G=56, B=92** (`0x12385C`).

### Hillshade (Elevation and Overlay land cells only)

Toroidal west and north neighbors (`floorMod`). Ocean is not hillshaded.

```
dw = e(x,y) - e(x-1, y)
dn = e(x,y) - e(x, y-1)
lit = clamp(12 + 2*dw + 2*dn, 6, 18)
c' = min(255, (c * lit) / 12)   // each of R, G, B
```

Flat land (`dw = dn = 0` ⇒ `lit = 12`) matches the unshaded land ramp.

### Plate colors

```
z = plateId * 0x9E3779B97F4A7C15
z = z XOR (z unsigned-shift-right 30)
R = 48 + (z AND 0x7F)
G = 48 + ((z unsigned-shift-right 8) AND 0x7F)
B = 48 + ((z unsigned-shift-right 16) AND 0x7F)
```

Java `long` wrapping. Same plate id → same RGB.

### Overlay

Elevation paint (ocean + hillshaded land), then if the cell’s plate id differs from its toroidal **east** or **south** neighbor, each RGB channel becomes `c / 3`.

### Speeds

| Speed | Period |
|-------|--------|
| Slow | 1000 ms |
| Normal | 250 ms (default) |
| Fast | 100 ms |

Default: **paused**. Dark window background: `0x12141A`.

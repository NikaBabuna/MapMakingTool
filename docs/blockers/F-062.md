# F-062 — Protocol shelf

**Goal:** G-011  
**Status:** `done`

## Job (approved)

Replace the scattered conduct files with `docs/protocol/` in four rooms: environment, navigation, blueprints, and flows. Writes happen only through a flow named in `environment/dispatch.md`. Each document kind the protocol already stores has one blueprint. Session is removed. The Active Goal line lives only on the goal index. The doors point at that index and at `docs/protocol/README.md`.

Product, architecture, and paperwork stay on their current paths. Their prose is not rewritten except where a link, a door, or an F-061 phrase test must follow the move. Simulation code does not change.

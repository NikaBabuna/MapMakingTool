# F-025 — Next.js tool UI

**Goal:** G-006  
**Status:** `done`

## Job (approved)

Add a Next.js front under `ui/web/` that talks to `MapHost` over HTTP. **Behavior** matches the Swing tool (layers, advance, play, seed, inspect, legend, console, busy). **Visuals** are intentionally better than Swing — that is why the front moves to Next. Play is client-timed `POST /api/advance`. Default host `http://127.0.0.1:7420` via `NEXT_PUBLIC_MAP_HOST`. No Tauri yet. No `engine` edits. Swing remains launchable until F-026.

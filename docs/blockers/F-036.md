# F-036 — Apply flux, flood, fission, death (+ B1 map distance)

**Goal:** G-008  
**Status:** `done`

## Job (approved)

Apply standing `area_flux` to plate geometry (SEPARATE grow / COLLIDE shrink→sink), flood leftover sink, **fission** disconnected components (cylinder 4-connected), **crumb absorb** (&lt; 0.05% of W×H), **death** (area 0), refresh `plate_registry`. Remap living plates to dense ids; inherit velocities; `plate_velocity` becomes STATIC so fission can expand it. Apply then advect inside `ApplyGeometry`. Also switch Step-0 / assign distance to **B1** latitude-weighted cylindrical metric. No IntegrateVelocity from intent (F-037); no orogeny-from-boundaries rewrite (F-038).

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Partition | **B1:** `dx_w = wrap(dx) * cosQ(y) / 1024`; `cosQ = max(1, round(1024 * sin(π*(y+0.5)/H)))`; `d² = dx_w² + dy²`; ties → lower site index |
| Sink sentinel | Plate id **−1** on grid during apply; none remain after flood |
| COLLIDE apply | Loser’s contact cell → sink |
| SEPARATE apply | Claim sink near contact for A then B (deterministic neighbor scan); skip if no sink |
| Flood | Remaining sink → adjacent living plate with longest local contact (tie: lower id); else B1-nearest living cell owner |
| Fission | Cylinder 4-connected (wrap X; no Y wrap); extra components get new ids; inherit parent `(vx,vy)` |
| Crumb | `area * 2000 < W*H` → absorb into longest-contact neighbor (tie: lower neighbor id) |
| Death / ids | Dense remap living ids ascending by previous id; rebuild registry + velocities |
| `plate_velocity` | **STATIC** (was CONSTANT); written with registry after geometry |
| Pipeline | One tectonics System: TraceBoundaries → BoundaryInteraction → ApplyGeometry → Orogeny |
| Out of scope | motion_intent integrate; orogeny rewrite; studio; latitude great-circle (B2) |

# F-019 — Product session + UI/CLI house

**Goal:** G-005  
**Status:** `done`

## Job (approved)

Make the modules match ADR-010, without changing tectonics. One **session** in `product` owns the `Engine` (create, serialized `advance`, read grids). Swing map shell moves to `ui`. `ui` and `cli` depend on `product`. Product has no Swing. Heartbeat launch is retired. Dump, Voronoi, suture `+1`, 8×8 / 512×512 stay as they are. Console and new commands wait for F-023.

**Out of scope:** plate motion, orogeny rewrite, tool chrome, CLI verbs, in-UI console.

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | Maven: `ui` → `product` → `engine`; `cli` → `product` → `engine`. Product does not depend on `ui` or `cli`. Engine still depends on none of them. | met |
| FR-2 | `product` main sources contain no Swing / `JFrame`. Map window types live in `ui`. | met |
| FR-3 | Product exposes a **session** (`ProductSession`): `WorldSpec` → run, `stepIndex`, serialized `advance`, read elevation and plates. No Swing. No CLI verb names on this type. | met |
| FR-4 | World rules unchanged: Step 0 Voronoi + zeros; generation still foreign-neighbor `+1`; `DEFAULT` 8×8 dump; `VIEW` 512×512. Same seed + N Steps → same grids. | met |
| FR-5 | Interactive map launches from **`ui`**. Headless tests never construct `JFrame`. `run-product.cmd` / docs point at the UI launch (or equivalent). | met |
| FR-6 | G-001 heartbeat as the thing you run is **superseded**. Engine loop stays witnessed by **engine** tests. F-007 / F-008 / F-013 / F-018 tests that required `ui`/`cli` ↛ `product` or `MapFrame` inside `product` are **rewritten** to the new house, not deleted without replacement. Incremental suite green. | met |

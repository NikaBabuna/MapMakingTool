# F-013 — Product Maven module + architecture

**Goal:** G-003  
**Status:** `done`

## Job (approved)

Stand up the product house: a `product` Maven module that depends on `engine`, with a recorded layout so F-014 does not invent names. Prove it from `product` tests: construct an `Engine` via `EngineSetup` through a product host (Step 0 completes). Skeleton `cli` / `ui` stay as they are. No grid, no elevation, no Systems, no wiki physics.

**Out of scope:** world geometry / `elevation` (F-014); emission policy, category tree, generative System (F-015); determinism fixture / ASCII dump as Goal closure (F-016); product CLI or UI; `engine` production source (F-001 scaffold *test* module-list update is required).

**Decisions (approved):** artifact `com.aethelgard:product`; package `com.aethelgard.product`; `ProductHost` factory; `docs/product/architecture.md`; landmark `product/README.md`.

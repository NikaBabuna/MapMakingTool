# F-007 — CLI runner

**Goal:** G-001  
**Status:** `done`

## Job (approved)

Create the **`cli` Maven module** (`com.aethelgard:cli`) that depends on `engine` (one-way), with a headless runner that creates an engine from config, advances **N** Steps, and prints the **settled** Pool state. Wire it into the parent aggregator so `mvnw test` still runs the full incremental suite.

**Out of scope:** UI (F-008), product Systems, rich CLI frameworks, interactive REPL.

**Skeleton decisions (approved):** package `com.aethelgard.cli`; `--steps N` and optional `--initial V`; testable `CliRunner`; `slf4j-simple` OK in cli; engine stays free of CLI deps.

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | Parent POM includes module **`cli`**; artifact `com.aethelgard:cli` depends on `engine`; `engine` has no reverse dependency. | met |
| FR-2 | CLI can run **N additional Steps** after create (N ≥ 0) from caller-supplied options / args. | met |
| FR-3 | After the run, CLI reports **settled** state: at least `stepIndex`, Pool `value`, `updateCount` (fields if present). | met |
| FR-4 | Invalid args (e.g. negative steps) fail with non-zero exit / clear error — no silent success. | met |
| FR-5 | Automated tests exercise the runner **headlessly** (no interactive stdin); full incremental suite (`engine` + `cli`) stays green via `mvnw test`. | met |
| FR-6 | Landmark `cli/` README + docs (architecture, navigation, changelog) updated for the new module. | met |

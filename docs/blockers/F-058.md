# F-058 — Buoyancy precedence + oceanic subduction + SEPARATE mint

**Goal:** G-010  
**Status:** `done`

## Job (approved)

At COLLIDE, oceanic crust subducts and continental crust does not vanish because its plate is smaller. Ocean–ocean keeps smaller-loses. Continent–continent neither sinks nor stamps (suture is F-059). After occupancy remap, a consumed oceanic locker is replaced by the surviving side’s locker id. At SEPARATE, new rift cells get **new** \(T_{ocean}=8\) lockers — not a copy of the contact locker (the live-map stripe hole F-057 did not cover). No suture/arc/cap, no locker GC, no crust-type layer, no atlas/sea-level paint change, no `engine` edits.

## Decisions (approved)

| Topic | Choice |
|-------|--------|
| Type grain | Per contact **cell**, standing locker thickness |
| \(T_{land}\) | **16** |
| O–C | Oceanic cell loses (sinks), even if its plate is larger |
| O–O | Smaller plate loses; area tie → lower id |
| C–C | Neither sinks; 0 flux; 0 stamps |
| One loser | Same rule for flux, geometry sink, stamps, slab pull |

| Orphans | No compact |
| Stamps | O–C / O–O keep +1/−1 with new polarity; C–C 0; SEPARATE −1 on standing contact lockers |
| Out of scope | Suture/arc/cap, locker GC, crust-type layer, weld, e=0 land-ramp paint, `engine` |

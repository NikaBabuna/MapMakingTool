# F-014 — World as Pool state (grid + elevation)

**Goal:** G-003  
**Status:** `done`

## Job (approved)

Put the world in the Pool: shared grid geometry and an `elevation` layer as a typed field. Step 0 is a seed (flat initial elevation), not a generated map. Document World / grid / layer in the wiki. No generative System, no climate, no engine production edits.

Extend `ProductHost` so every product run wires the schema and seeds the grid. F-013’s “create completes Step 0” stays true.

**Out of scope:** elevation process (F-015); determinism/ASCII Goal closure (F-016); plates layer; product CLI/UI; CLI README launch fix; engine production source.

**Decisions (approved):** `WorldSpec(width, height, seed)`; field `elevation` is an immutable `Grid` of `int` cells; Step 0 every cell `0`; merge `FieldType.STATIC`; `create()` defaults to 8×8 seed `0`; plates deferred to F-015; package stays `com.aethelgard.product`; wiki `docs/product/wiki/world.md`.

## Functional requirements (approved)

| ID | Requirement (measurable) | Status |
|----|--------------------------|--------|
| FR-1 | `ProductHost.setup()` declares field `elevation` with a `FieldMergeType` (default Static). Settled type is a product `Grid`, not `Long`. | met |
